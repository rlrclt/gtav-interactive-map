# GTA V Interactive Map (Real-time Sync)

Interactive GTA V map (Los Santos & Blaine County) with Leaflet, multi-timers per marker, and real-time synchronization across all players.

## Deploy to Render.com (Free)

1. Sign in to [Render.com](https://render.com)
2. Click **New +** -> **Web Service**
3. Connect this repository: `rlrclt/gtav-interactive-map`
4. Configure:
   - **Environment:** `Python 3`
   - **Build Command:** *(leave empty or `pip install --upgrade pip`)*
   - **Start Command:** `python3 server.py`
5. Click **Deploy Web Service**
